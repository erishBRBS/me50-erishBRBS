# CS50W Project 0: Search

This is my submission for CS50W Project 0: Search.

## Description

This project is a front-end implementation for Google Search, Google Image Search, and Google Advanced Search using HTML and CSS.

## Features

- Google Search page
- Google Image Search page
- Google Advanced Search page
- "I'm Feeling Lucky" button
- Search forms that redirect to Google search results
- Styling inspired by Google's interface

## Files

- `index.html` - Main Google Search page
- `images.html` - Google Image Search page
- `advanced.html` - Google Advanced Search page
- `styles.css` - CSS styles for all pages

## How to Run

Open `index.html` in a web browser.

## Demo Checklist

- User can search using the main search page
- User can search images
- User can use advanced search fields
- User can use the "I'm Feeling Lucky" button
